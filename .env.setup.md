# Environment Setup Guide

## Firebase Configuration

The error `auth/invalid-api-key` means your `.env` file is either missing or has invalid Firebase credentials.

### Steps to get your Firebase config:

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project (`netflix-clone-1047b`)
3. Click **Settings** (gear icon) → **Project Settings**
4. Under **Your apps**, find your web app (or create one)
5. Copy the Firebase SDK config and fill `.env`:

```
VITE_FIREBASE_API_KEY=<your_apiKey>
VITE_FIREBASE_AUTH_DOMAIN=<your_authDomain>
VITE_FIREBASE_PROJECT_ID=<your_projectId>
VITE_FIREBASE_STORAGE_BUCKET=<your_storageBucket>
VITE_FIREBASE_MESSAGING_SENDER_ID=<your_messagingSenderId>
VITE_FIREBASE_APP_ID=<your_appId>
```

Example from console:
```javascript
const firebaseConfig = {
  apiKey: "AIzaSyD...",
  authDomain: "netflix-clone-1047b.firebaseapp.com",
  projectId: "netflix-clone-1047b",
  storageBucket: "netflix-clone-1047b.appspot.com",
  messagingSenderId: "714211560101",
  appId: "1:714211560101:web:e2d64a2c0fa621db309b4c"
};
```

Map each field to `.env`:
```
VITE_FIREBASE_API_KEY=AIzaSyD...
VITE_FIREBASE_AUTH_DOMAIN=netflix-clone-1047b.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=netflix-clone-1047b
VITE_FIREBASE_STORAGE_BUCKET=netflix-clone-1047b.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=714211560101
VITE_FIREBASE_APP_ID=1:714211560101:web:e2d64a2c0fa621db309b4c
```

## TMDB Bearer Token

1. Go to [TMDB Developer Account](https://www.themoviedb.org/settings/api)
2. Under **API**, copy your **Bearer Token**
3. Add to `.env`:

```
VITE_TMDB_BEARER=eyJhbGciOiJIUzI1NiJ9...
```

## Verify Setup

After creating `.env`:

```bash
# Development server
npm run dev

# Build
npm run build
```

The app should now load without the Firebase error. If you still see `auth/invalid-api-key`, double-check:
- Firebase API key is correct and active in Firebase Console
- No extra spaces or quotes in `.env` values
- `.env` file is in the project root (same level as `package.json`)
